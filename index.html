Розрізати весь файл на частини
Довжина кожної частини в хвилинах. Остання частина буде коротшою, якщо файл не ділиться націло.
Як користуватись: перемотай плеєр на потрібне місце і натисни «З плеєра» для початку та кінця. Точніше підлаштуй кнопками ± або впиши час вручну (наприклад 1:23:45.5). Різання йде по MP3-кадрах (~26 мс), тож без втрати якості. Якщо в файлі змінний бітрейт (VBR) без заголовка, позиція плеєра може трохи розходитись із реальним часом — перевіряй кнопкою «Прослухати вибране».
